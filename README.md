# Food Delivery App

Aplicação de delivery em desenvolvimento para praticar construção de sistemas web, conectando lógica de back-end iniciada com uma interface front-end funcional.

## Demonstração

Acesse a versão publicada no GitHub Pages:

[Ver demonstração online](https://fernandotechseeker.github.io/food-delivery-app/)

## Visão geral

O **Food Delivery App** simula uma aplicação de delivery com foco em fluxo de produtos, carrinho e resumo de pedido.

O projeto está sendo estruturado como uma aplicação full-stack em evolução: a base de back-end foi iniciada e o front-end foi desenvolvido para demonstrar a experiência visual e interativa do usuário.

## Objetivo do projeto

Criar uma aplicação prática para demonstrar:

- interface de cardápio;
- listagem de produtos;
- adição de itens ao carrinho;
- cálculo de total do pedido;
- simulação de finalização de pedido;
- estrutura visual responsiva;
- evolução futura para integração com back-end.

## Tecnologias utilizadas

- Git

## Funcionalidades atuais

- Página inicial responsiva
- Seção de produtos
- Cards de produtos dinâmicos via JavaScript
- Carrinho interativo
- Soma automática do pedido
- Mensagem de finalização demonstrativa
- Layout responsivo para desktop e celular

## Funcionalidades previstas
