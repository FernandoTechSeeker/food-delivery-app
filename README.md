# 🍽️ Food Delivery App

Aplicativo de entrega de comida desenvolvido para praticar habilidades em desenvolvimento web. O projeto simula uma plataforma onde usuários podem explorar restaurantes, montar pedidos e acompanhar entregas.

## 🚀 Funcionalidades

- Visualização de restaurantes e cardápios
- Adição de itens ao carrinho
- Sistema de pedidos
- Cadastro/login de usuários
- Tela de rastreamento de entrega
- Layout responsivo
